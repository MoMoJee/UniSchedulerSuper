# 2026-11-05 日历事件可扩展 Payload

- 为 `CalendarEvent` 增加可选 `payload` JSON 字段（迁移 `0014_calendar_event_payload`），按注册名保存第三方扩展数据。
- 新增 `core/planner/payloads.py`：统一注册名表、Key/Entry 结构校验、UTF-8 大小限制与轻量 JSON Schema 校验；未知注册名/格式透传保留。
- 创建与 `scope=all` 更新支持 `payload`；重复系列 occurrence 继承 master，split/detach 复制原 payload；`single`/`future` 写 payload 返回 `422 payload_scope_not_supported`。
- definitions、occurrences、conflicts、search、shared occurrences 默认返回 `payload`，`include_payload=0` 可关闭。
- 已注册 `org.uss.scheduler` 及 schema 文件；新增 `docs/日历事件Payload机制.md`、API 参考与 V2 示例脚本。
- 测试：`core/tests/test_planner_event_payload.py` 16 个用例覆盖双注册名隔离、无 Payload 事件、未知 Key/格式、schema 拒绝、大小限制、scope、split/detach 和查询开关；`manage.py check`、迁移检查通过。
